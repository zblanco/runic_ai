# Legacy Full-Stack RunicAI Archive

This directory preserves the former full-stack RunicAI application as research
reference while RunicAI Core is rewritten at the repository root.

- Source branch: `archive/full-stack-legacy-2026-08-15`
- Source commit: `f70c3fd`
- Archived on: 2026-08-15
- Baseline verification: `1134 tests, 0 failures, 3 skipped`

The archive includes the former application source, tests, configuration,
documentation, guides, Livebooks, browser harness, persistence system,
Workbench, coding/RLM experiments, and package metadata.

It is intentionally outside root `lib`, `test`, and package file lists. New
RunicAI Core code must not compile, import, or call archived modules.

Automated and browser evidence recorded in the archive remains useful technical
evidence. It does not establish the still-open real-human comprehension gate.

## 0.1.0 - Unreleased

Initial public release candidate for RunicAI.

Highlights:

- Workflow-native AI contracts for messages, prompts, conversations, LLM
  requests, LLM results, agent turns, tools, controls, context, decomposition,
  integrated state, traces, harnesses, evaluation, runtime sessions, and
  RLM-style long-context workflows.
- Reference recipes for chat agents, tool agents, guarded tool agents,
  context-aware agents, delegated workflows, integrated stateful agents,
  evaluation harnesses, and long-document summarization.
- ExDoc configuration with grouped modules, guide extras, Livebook extras, and
  Mermaid diagram rendering.
- README-driven top-level moduledoc and public documentation plan for release
  polish.

Release gates before publishing:

- Confirm and add the project license.
- Run the release checklist in `guides/reference/release-checklist.md`.
- Complete real application trial scenarios that cover docs QA, release checks,
  runtime operation, and evaluation.
